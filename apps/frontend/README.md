# Frontend

The frontend is the operator-facing dashboard for the ESL platform. It presents label data, device status, and pricing workflows in a form that store teams can use day to day.

## Role in the System

- Provides the primary user experience for viewing shelf label information.
- Allows users to trigger pricing actions that flow through the platform.
- Displays live feedback so operators can quickly understand current device state.

## Why It Matters

This module turns system capabilities into practical workflows. It is where platform reliability and responsiveness are most visible to end users.

## Audience

New contributors should view this module as the presentation layer that connects business operations to backend-driven and device-driven events.
